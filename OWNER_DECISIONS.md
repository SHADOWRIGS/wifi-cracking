# Owner Decisions

Questions for the repository owner regarding potential further improvements.

## 1. Update Chinese translations (README.zh.md, appendix.zh.md)?

The "Note on Modern Tools" section was added only to the English README. The Chinese versions also contain the same typos as the English appendix (but in translated form). Should the Chinese docs be updated to match?

## 2. Deprecate naive-hashcat references?

The `naive-hashcat` tool referenced throughout the tutorial hasn't been actively maintained. Should the tutorial shift primary recommendation to direct `hashcat` usage with modern workflow (hcxpcapngtool + mode 22000)?

## 3. Add CONTRIBUTING.md?

The project has many community contributors listed in the attribution section. Would a CONTRIBUTING.md help guide future contributions?

## 4. Update external links?

Some links in the tutorial may be stale (e.g., wirelesshack.org device list from 2016, GPUHASH.me, OnlineHashCrack). Should these be verified and updated or removed?
